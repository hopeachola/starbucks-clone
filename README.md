# Starbucks Landing Page Clone

A front-end UI recreation of the Starbucks web experience built to practice modern layout structure, visual hierarchy, and responsive web design.

## Overview
This repository replicates core sections of the Starbucks homepage, including promotional banners, seasonal drink highlights, and navigation bars.

## Technologies Used
- **HTML5** — Semantic layout and navigation components.
- **CSS3** — Flexbox/Grid alignment, brand color palette, and responsive breakpoints.

## How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Open `index.html` directly in your web browser.
